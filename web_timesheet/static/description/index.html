Zakheni ICT Timesheet Portal


This module, developed by Zakheni ICT (Pty) Ltd, enables users, whether they are internal users, portal users, or public users to record their timesheets without requiring an Odoo license. It removes the previous restriction where only licensed users could log their time, providing a cost-effective solution for organizations. Now, users who only need access to timesheets can record their data without the need for a full Odoo license, helping reduce overall licensing costs.


Portal Features




Before accessing the portal, please ensure the following pre-requisites are in place


  1. A portal user account has been created.
  2. The portal user is linked to the corresponding employee to allow access to the Timesheet module.
  3. A project has been configured and includes the necessary tasks.
