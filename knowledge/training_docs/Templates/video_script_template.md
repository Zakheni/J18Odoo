## 4. Scene-by-Scene Script

| Scene # | Duration | On-Screen Action | Narration (Voiceover) |
|---|---|---|---|
| 1 | 0:00–0:20 | **Opening title card** with module name and video title. | "Welcome to this training series on [Module]. In this video, we'll cover [topic]." |
| 2 | 0:20–0:45 | **Screen capture:** Odoo dashboard → Quality app (click). **Overlay arrow** pointing to the Quality icon. | "Start by opening the Quality app from your Odoo dashboard. If you don't see it, check that your user has Quality access rights." |
| 3 | 0:45–1:30 | **Screen capture:** Navigate to Configuration → Inspection Points. Click **New**. **Mouse highlight** on the Name field. Fill in fields one by one with pauses. | "Go to Configuration then Inspection Points. Click New. Give it a descriptive name — for example, 'Inspect raw material X on receipt'. Then choose the control type: Product or Picking." |
| 4 | 1:30–2:15 | **Screen capture:** Select Control Type = Product, pick a product, set trigger to *On Confirmation*. **Close-up** on the Save button. Click Save. | "Select Product, then choose the product you want to inspect. Set the trigger to 'On Confirmation' so the check fires automatically when the receipt is confirmed. Click Save." |
| 5 | 2:15–3:00 | **Screen capture:** Go to Warehouse → Receipts → validate a receipt for that product. Show the **quality check pop-up** or the check appearing in the Quality Checks list. | "Now let's see it in action. Go to Warehouse and validate a receipt for this product. Notice that a quality check is automatically created. Open it to record the result." |
| 6 | 3:00–4:00 | **Screen capture:** Open the check → select Pass/Fail → enter a note → click Confirm. Then show the check status changing to *Passed*. | "Inside the quality check, record whether it passed or failed. You can add a note with observations. Click Confirm to finalise. The status updates to Passed." |
| 7 | 4:00–4:20 | **Screen capture:** Click **Create Non-Conformity** on a failed check. Show the NC form pre-filled. | "If the check fails, click 'Create Non-Conformity'. This pre-fills a problem report. Add the severity and assign a responsible person." |
| 8 | 4:20–4:30 | **Closing title card** with key takeaways and *Next Video* link. | "And that's how you set up and use inspection points. In the next video, we'll cover non-conformity management in more detail. Thanks for watching." |
