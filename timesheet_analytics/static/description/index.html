Zakheni ICT Timesheet Analytics


This module, developed by Zakheni ICT (Pty) Ltd, provides advanced analytics capabilities for timesheet data across the organization. It enables internal users, portal users, and public users to seamlessly capture timesheet entries without requiring an Odoo license, while simultaneously transforming this data into meaningful and actionable insights.

In many cases, employers are unable to obtain sufficiently accurate data to support informed decision-making when relying solely on standard system reports. Zakheni ICT addresses this gap by delivering enhanced and detailed analytics that empower management to make more precise and strategic decisions.

These include resource allocation and workload management, as the analytics provide clear visibility into which resources are actively engaged and which are available for allocation.

Features




Before accessing the timesheet analytics, please ensure the following pre-requisites are in place


  1. Zakheni ICT Timesheet module has been successfully installed. It is also available on the Odoo App Store for reference.
  2. The portal user is linked to the corresponding employee to allow access to the Timesheet module.
  3. A project has been configured and includes the necessary tasks.
